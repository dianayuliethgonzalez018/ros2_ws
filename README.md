## Bienvenido

Cuando empecé con ROS 2 me encontré con muchísima información y no sabía qué aprender primero. Probé varios tutoriales, leí la documentación oficial e incluso hice algunos cursos. Aun así, me costaba encontrar un camino claro para empezar.

Este repositorio nace para organizar ese camino.

Aquí documento todo lo que voy aprendiendo mientras construyo proyectos con ROS 2, con la esperanza de que a cualquier persona que quiera empezar le resulte mucho más fácil dar sus primeros pasos.

No soy un experto escribiendo un manual. Soy alguien que está aprendiendo, cometiendo errores, resolviendo dudas y documentando el proceso para que otros puedan aprovechar ese recorrido.

Si este repositorio consigue ahorrarte horas de confusión o ayudarte a entender un concepto que al principio parecía complicado, sentiré que todo este recorrido habrá valido la pena.

---

## ¿Qué puedes esperar de este repositorio?

Cada capítulo sigue la misma idea:

- Entender qué problema vamos a resolver.
- Explicar el concepto sin asumir conocimientos previos.
- Aplicarlo inmediatamente con una práctica.
- Documentar lo aprendido.
- Continuar con el siguiente paso.
